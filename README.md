# Weeks 5-8: Deep Dive into Neural Networks

## Overview

In Weeks 5-8, we'll deepen our understanding of neural networks by exploring various activation functions, optimization techniques, and advanced architecture components. The focus is on both the theoretical and practical aspects of deep learning, ensuring that you not only implement but also truly understand the inner workings of these models.

---

## Core Reading Materials

- **Neural Networks and Deep Learning** by Michael Nielsen  
  *Primary Text:* Focus on chapters covering backpropagation and network architecture.

- **Deep Learning** by Goodfellow, Bengio, and Courville  
  *Chapters 6-9* for deeper theoretical insights.

- **Original Backpropagation Paper:**  
  "Learning representations by back-propagating errors" by Rumelhart and Hinton  
  Understand the foundational concepts that drive modern deep learning.

- **Alternate Resource:**  
  [Neural Networks: Zero to Hero (Video)](https://youtu.be/VMj-3S1tku0?si=zxOqrWtNO4w8WMms)  
  Part of Andrej Karpathy's series that covers all the above topics.

---

## Implementation Schedule

### Weeks 5-6: Core Neural Network Components

- **Forward Propagation:**  
  Implement forward propagation from scratch to understand the data flow through the network.

- **Backpropagation:**  
  Derive and implement backpropagation (as part of building an autograd engine from scratch) to understand gradient computation.

- **Activation Functions:**  
  Experiment with various activation functions such as ReLU, Sigmoid, and Tanh.

- **Optimization Techniques:**  
  Build and compare different optimization methods:
  - Stochastic Gradient Descent (SGD)
  - Momentum
  - Adam

- **Focus:**  
  Deeply understand how gradients flow through the network and how these influence learning.

### Weeks 7-8: Advanced Architecture Components

- **Batch Normalization:**  
  Implement and understand the role of batch normalization in training deep networks.

- **Dropout Layers:**  
  Add dropout layers for regularization to prevent overfitting.

- **Weight Initialization:**  
  Experiment with different weight initialization methods to improve training stability.

- **Performance Optimization:**  
  Focus on debugging techniques and performance optimizations.

- **Testing and Validation:**  
  Develop robust testing and validation strategies to evaluate your network.

---

## Main Project: Modular Neural Network Framework

- **Objective:**  
  Build a modular neural network framework using pure Python and NumPy, without relying on high-level deep learning libraries.

- **Features:**
  - Modular design to easily swap and compare different network components.
  - Visualization of the training process to monitor learning.
  - Comparative analysis of various components and techniques.
